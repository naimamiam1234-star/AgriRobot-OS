# AgriRobot OS — 0.1 development sources

نواة برمجية أولية لروبوت زراعي، مع مكتبة صور ومصادر وصيغة بناء ISO تجريبية. **ليس ملف ISO جاهزًا، ولا روبوتًا مكتملًا، ولا نموذج أمراض مدربًا.**

## تشغيل البرنامج الآن

يحتاج Python 3.12؛ وظائف السجل وخدمة JSON والبحث لا تحتاج حزمًا خارجية أو إنترنت.

```bash
python3 -m unittest discover -v
python3 -m app.catalog --verify
python3 -m app.catalog Tomato
python3 -m app.catalog 'الذبابة البيضاء'
python3 -m app.server --data runtime
```

البرنامج يبدأ على 127.0.0.1:8080، ويولد مفتاح المشغل في runtime/operator.token بصلاحية خاصة. /health متاح محليًا؛ /status و/events وباقي الطلبات تحتاج Authorization: Bearer مع المفتاح. لا تشغله على منفذ إنترنت عام. الوصول من هاتف يحتاج إعداد شبكة ومصادقة ونقل آمن؛ لا يوجد إعداد بعيد تلقائي في هذا الإصدار.

الأوامر POST /simulation/enable وPOST /dose تعمل **بالمحاكاة فقط**. طلب الجرعة JSON يحتوي request_id وplant_id وvolume_ml وapproved=true. القيم القصوى الحالية (500ml للطلب و2000ml يوميًا للنبتة) حدود اختبار للمحاكاة، وليست توصيات زراعية. السماد مرفوض حتى إضافة وصفة ومعايرة حقيقية. POST /stop يوقف الحالة البرمجية، ولا يعوض زر طوارئ ماديًا.

## الموجود في المجلد

- app/: سجل SQLite ومتحكم محاكاة وخدمة محلية ووصلات اختيارية للذكاء الاصطناعي وفهرس صور.
- tests/: اختبارات الجرعات والتكرار والطوارئ والمصادقة والمدخلات والنقل المحلي وتكامل المصادر.
- data/images/: صور مرجعية حقيقية، مع manifests للتراخيص والمصادر والبصمات.
- data/sources.json: دليل مصادر الأمراض والحشرات.
- data/plantdoc-full-source-index.json: فهرس روابط صور المجموعة الأوسع؛ الملفات الإضافية غير منزلة.
- iso/: وصفة صورة Ubuntu Live تجريبية وخدمة systemd وإعداد GRUB.
- .github/workflows/: اختبارات وبناء ISO اختياري عند الطلب؛ لم يُشغّل على GitHub بعد.
- docs/: التصميم والخطة ودليل المصادر وحالة الإنجاز وطريقة البناء.

وصلات LocalAI تحتاج ملفات النماذج ومحركاتها أولًا؛ لم نختبر استدلالًا حقيقيًا بعد. لا صور اصطناعية في المكتبة. الصور ليست تقسيم تدريب/اختبار. انظر docs/SOURCES-ar.md وملفات manifests عند إعادة توزيعها.

## الخطوة التالية

تثبيت مصادر البناء في بيئة مناسبة، إضافة أوزان مرخصة بمراجعات وبصمات محددة ومحركاتها، تطوير الواجهة وROS ووصلات STM32، ثم اختبار الإقلاع والاستدلال والعتاد. تفاصيل ما نُفذ وما لم يُنفذ في docs/STATUS.md. لا يوجد وعد بزمن إقلاع قبل القياس.
