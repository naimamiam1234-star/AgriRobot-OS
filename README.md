# AgriRobot OS — offline AI development

نظام Ubuntu 24.04 Live للحاسوب amd64، مع برنامج محلي ومكتبة صور زراعية ومحركات ذكاء اصطناعي تعمل دون إنترنت بعد تجهيز الصورة. حالة البناء والاختبار الفعلية في [GitHub Actions](https://github.com/naimamiam1234-star/AgriRobot-OS/actions)؛ لا تعتبر محاولة غير مكتملة إصدارًا جاهزًا.

## مكونات صورة 0.3

- محادثة Qwen3-0.6B Q4_0 عبر llama.cpp؛ يبدأ عند الطلب لتقليل عبء الإقلاع.
- تحويل الصوت إلى نص عبر Whisper tiny وwhisper.cpp؛ إخراج صوت عربي عبر eSpeak NG.
- رؤية YOLO11n بصيغة ONNX وتشغيل CPU خفيف دون PyTorch في النظام الهدف؛ كاشف أجسام عام، وليس نموذج تشخيص أمراض أو مصنف حشرات.
- أرشيف PlantDoc الكامل: 2578 صورة متحقق منها، و33 صورة مرجعية مختارة مع تراخيصها ومصادرها.
- سجل SQLite، متحكم محاكاة، API محلي مصادق عليه، وفهرس صور يعمل دون شبكة.
- أوزان ومصادر محركات مثبتة بالمراجعة والحجم وSHA256 في config/assets.lock.json.

البناء ينفذ استدلالًا حقيقيًا في rootfs معزول عن الشبكة قبل إنشاء ISO. ثم يختبر الإقلاع الفعلي للصورة على QEMU بنمط BIOS وUEFI دون بطاقة شبكة. تقارير كل محاولة ضمن مخرجاتها؛ فشل الاختبار لا يتحول إلى نجاح بمجرد وجود ملف ISO.

## التشغيل

[دليل الذكاء المحلي والأوامر](docs/OFFLINE-AI-v0.3-ar.md) · [البناء والتحقق](docs/BUILD.md) · [الحالة](docs/STATUS.md) · [المصادر والتراخيص](docs/SOURCES-ar.md) · [تعريف المتحكمات وأدلة التوصيلات](docs/Controller-Self-Description-v1.md).

```sh
python3 -m app.catalog --verify
python3 -m app.catalog 'الذبابة البيضاء'
python3 -m app.server --data runtime
```

الخدمة على 127.0.0.1:8080. المفتاح في runtime/operator.token؛ /health محلي، وباقي الطلبات تحتاج Authorization: Bearer. جرعات الماء والتمكين والإيقاف محاكاة فقط. لا تفتح الخدمة على الإنترنت مباشرة.

اختبارات المصدر تحتاج Python 3.12 وNumPy 1.26.4 لاختبارات الرؤية؛ البرنامج الأساسي والفهرس لا يحتاجان حزمًا خارجية. تفاصيل بيئة الاختبار في دليل البناء.

## ما لم يكتمل

التحكم المادي والحركة، firmware المتحكمات، معايرة الماء والسماد، نموذج زراعي متخصص مدرب ومقيم، واجهة رسومية كاملة وROS. الصور المرجعية لا تعني أن نموذجًا تدرب عليها. لا يوجد ادعاء بوعي ذاتي؛ تعريف القطع يعتمد على ملفات وأدلة قياس ولا يستنتج جميع التوصيلات من GPIO. تخزين Live قد يكون مؤقتًا؛ اختبارات الحاسوب والمحاكاة لا تثبت صلاحية التشغيل الحقلي أو سرعة لوحة الروبوت.

## مهارات التطوير

أضيفت 23 مهارة تطوير وتنسيق مع المصادر والتراخيص وبصمات الملفات؛ راجع [دليل الدمج](docs/ROBOTICS-SKILLS-ar.md). الصورة السابقة اجتازت [اختبار BIOS/UEFI المستقل](https://github.com/naimamiam1234-star/AgriRobot-OS/actions/runs/39193640954). تحديث ملفات المهارات يدخل في البناء التالي، ولا يعيد تدريب النماذج.
