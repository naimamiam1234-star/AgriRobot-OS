# Model installation state

No model weights, inference binaries or downloaded Python dependencies are included in this source package. The application reports unavailable until they are installed. This package is not yet a complete offline AI distribution.

Candidates and primary sources:

- Qwen3-0.6B: https://huggingface.co/Qwen/Qwen3-0.6B
- GGUF variants: https://huggingface.co/ggml-org/Qwen3-0.6B-GGUF
- llama.cpp: https://github.com/ggml-org/llama.cpp
- whisper.cpp and model instructions: https://github.com/ggml-org/whisper.cpp
- Piper: https://github.com/OHF-Voice/piper1-gpl
- Voice model cards: https://huggingface.co/rhasspy/piper-voices
- YOLO11: https://docs.ultralytics.com/models/yolo11/
- Optional future image description: https://huggingface.co/HuggingFaceTB/SmolVLM2-256M-Video-Instruct

Before bundling: pin the source revision, verify download size and SHA256, preserve model card and license, benchmark inference on the target CPU and ensure redistribution is allowed. General YOLO weights are not a plant disease or IP102 classifier. Never rename a general detector as a trained agricultural model.
